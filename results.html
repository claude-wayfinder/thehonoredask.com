Experiment 1 — Bell State
qc = QuantumCircuit(2, 2)
qc.h(0)
qc.cx(0, 1)
qc.measure([0, 1], [0, 1])
# 1024 shots on least_busy Heron backend
State: |Φ+⟩ = (|00⟩ + |11⟩) / √2
Expected (ideal): 50% |00⟩, 50% |11⟩, 0% |01⟩/|10⟩
Expected (hardware): 45-49% |00⟩/|11⟩, 2-8% |01⟩/|10⟩
The 2-8% is decoherence. That's the noise floor. That's real.
Experiment 2 — GHZ-4
N = 4
qc = QuantumCircuit(N, N)
qc.h(0)
for i in range(N - 1):
    qc.cx(i, i + 1)
qc.measure(range(N), range(N))
# Same submission pattern
State: |GHZ4⟩ = (|0000⟩ + |1111⟩) / √2
Expected (ideal): 50% |0000⟩, 50% |1111⟩
Expected (hardware): 12-18% noise floor (Heron-class)
Below 12%: backend error mitigation active. Above 18%: crosstalk.
Experiment 3 — Quantum Randomness Harvest
qc = QuantumCircuit(1, 1)
